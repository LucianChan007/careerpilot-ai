# CareerPilot AI

AI大学生实习求职研究与投递助理

## 项目简介

CareerPilot AI 是一款面向大学生的 AI 求职智能助理，
帮助用户完成岗位研究、岗位匹配、简历优化、面试准备
以及求职过程管理。

## 项目目标

解决大学生在实习求职过程中：

1. 岗位筛选困难
2. JD 信息理解成本高
3. 简历与岗位匹配不足
4. 面试准备效率低
5. 投递记录管理混乱

等问题。

## 核心功能

- 用户求职画像
- 岗位 JD 智能解析
- 岗位匹配分析
- 简历针对性优化
- 面试准备
- 求职长期记忆
- 投递进度管理
- AI 求职复盘

## 项目管理

项目采用敏捷开发模式，
使用飞书多维表格进行项目管理。

项目采用两个跨职能 Pod 协作。
