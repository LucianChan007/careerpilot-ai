# Sprint 1 Plan

## Sprint Goal

完成 CareerPilot AI 第一条 MVP 闭环：

简历上传
→ 个人求职画像
→ JD 解析
→ 岗位硬性条件匹配

## Sprint Scope

- US01 简历解析
- US02 个人求职画像编辑
- US03 JD 解析
- US04 硬性条件匹配

## Story Point

Total: 16

## Expected Deliverable

用户可以上传自己的简历并输入岗位 JD，
系统能够解析双方信息，并输出岗位硬性条件匹配结果。

## Definition of Done

一个 User Story 必须满足：

1. 功能可以实际运行
2. 核心流程可以完成
3. 至少经过一次人工测试
4. 没有阻断核心流程的 Bug
5. 验收标准全部满足
6. 代码已提交 GitHub
7. 飞书状态更新为 Done
