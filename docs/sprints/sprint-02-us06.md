# Sprint 2 - US06 项目/经历匹配

## 1. User Story

**US06：分析项目/经历与岗位匹配程度**

作为大学生求职者，我希望系统能够分析岗位实际工作内容，并将其与我的项目经历和实习经历进行对应，从而判断自己过去的经历与岗位工作内容之间的匹配程度。

## 2. 需求来源

US05 完成后的功能迭代。

US05 主要分析技能要求，而 US06 进一步分析岗位实际工作内容与用户项目、实习经历之间的对应关系。

## 3. Sprint 目标

1. 提取岗位中的主要工作内容。
2. 读取用户项目经历。
3. 读取用户实习经历。
4. 建立岗位工作内容与用户经历之间的对应关系。
5. 输出逐项匹配状态。
6. 展示匹配证据。
7. 没有相关经历时明确说明。
8. 输出整体项目/经历匹配结论。

## 4. 实现内容

### 后端

- 新增 `experience_schema.py`
- 新增 `experience_service.py`
- 新增 `POST /api/jd/experience-match`
- 读取当前用户个人画像
- 读取岗位职责和工作内容
- 分析项目经历和实习经历
- 输出工作内容与用户经历的对应关系

### 前端

- 新增 `experience.html`
- 展示岗位基本信息
- 展示岗位工作内容
- 展示对应项目/实习经历
- 展示匹配状态
- 展示匹配依据
- 展示未发现相关经历的情况
- 展示整体项目/经历匹配结论

## 5. 验收标准

### 工作内容分析

系统能够从岗位职责中识别主要工作内容，并逐项分析。

### 经历匹配

每项工作内容均需要判断：

- 匹配
- 部分匹配
- 信息不足
- 不匹配

### 证据

系统需要明确指出对应的：

- 项目经历
- 实习经历

以及具体匹配依据。

### 无相关经历

如果用户个人画像中没有相关经历，必须明确显示没有找到相关经历，不得虚构。

### 整体结论

系统能够综合各项工作内容的匹配情况输出整体结论。

## 6. 测试案例

### 测试案例 A

岗位：

C++开发实习生

主要工作内容：

- 使用 C/C++ 进行软件开发
- 软件测试
- 架构设计
- 数据库交互

测试用户：

陈韬真实个人画像。

检查项目和实习经历是否与上述工作内容存在明确对应关系。

### 测试案例 B

岗位增加用户没有明显经历的工作内容。

例如：

- Rust 底层系统开发
- CUDA GPU 优化

检查系统是否明确显示没有发现相关经历，而不是虚构经历。
