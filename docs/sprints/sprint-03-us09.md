# US09：JD 定制简历修改建议

## 1. 基本信息

- **用户故事编号：** US09
- **所属迭代：** Sprint 3
- **功能名称：** JD 定制简历修改建议
- **功能状态：** Done（正常输入场景已验证）

## 2. 用户故事

作为正在寻找实习岗位的软件工程本科生，我希望系统能够结合目标岗位 JD、个人技能匹配结果和项目经历匹配结果，生成针对性的简历修改建议，以便更准确地展示真实能力，提高简历与目标岗位之间的相关性。

## 3. 功能目标

1. 根据目标岗位提炼简历应该突出的重点。
2. 提供与目标岗位相关的求职定位建议。
3. 针对技能、项目和实习经历提出修改方向。
4. 生成可供候选人参考和修改的文本草稿。
5. 列出需要核实的信息，避免虚构技能、经历和项目成果。
6. 不自动覆盖或修改候选人的原始简历。

## 4. 实现内容

- `backend/app/resume_advice_schema.py`：定义简历修改建议的数据结构。
- `backend/app/resume_advice_service.py`：构造模型提示词、调用模型、解析并标准化输出。
- `backend/app/main.py`：集成 `POST /api/jd/resume-advice` 接口。
- `backend/static/resume-advice.html`：提供简历修改建议页面。
- 页面入口：`/resume-advice`。

该功能结合候选人画像、目标岗位信息、技能匹配结果以及项目和实习经历匹配结果生成建议。

## 5. 验收标准

| 编号 | 验收内容 | 验收要求 |
|---|---|---|
| AC01 | 输入关联 | 能够结合候选人画像和目标岗位 JD 生成建议 |
| AC02 | 岗位定位 | 能够生成整体修改方向和建议的求职定位 |
| AC03 | 经历优化 | 能够指出技能、项目或实习经历的调整方向 |
| AC04 | 文本草稿 | 能够生成供候选人参考的简历修改文本 |
| AC05 | 事实约束 | 不得虚构技能、经历、技术栈或量化成果 |
| AC06 | 页面展示 | 能够在页面中展示生成的建议和待核实事项 |
| AC07 | 原始资料保护 | 生成建议时不自动覆盖原始简历 |

## 6. 测试与验收记录

### 测试场景

- 测试岗位：C++ 开发实习生。
- 测试页面：`/resume-advice`。
- 测试输入：候选人个人画像、目标岗位 JD，以及系统已有的技能和经历匹配结果。

### 实际测试结果

本地页面成功生成简历修改建议，主要包括：

1. 整体修改方向。
2. 建议的求职定位。
3. 对 C++ 技能、软件开发、测试验证、问题定位与修复、数据处理和运维开发经历的组织建议。
4. 对 Qt、桌面开发经验、开发工具和测试工具等缺少明确证据的内容进行提示。
5. 提醒候选人核实技术栈、项目职责和成果数据，不得使用不真实的信息。
6. 明确说明生成内容属于简历修改建议和文本草稿，不会自动修改原始简历。

### 测试结论

正常输入场景通过，满足本次核心功能的基本验收要求。

本次记录仅覆盖上述正常输入场景，不代表空输入、模型超时和所有异常输出场景均已通过测试。
