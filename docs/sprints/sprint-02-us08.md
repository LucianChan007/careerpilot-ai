# Sprint 02 - US08 能力 Gap 与补强建议

## 1. User Story

**US08：能力 Gap 与补强建议**

作为一名正在寻找实习岗位的大学生，我希望系统能够结合岗位技能要求、项目职责和我的现有经历，识别当前能力或经历方面的差距，并提供有优先级、有验收标准的补强计划，以便更有针对性地进行学习和求职准备。

## 2. 优先级与 Sprint

- 优先级：P0
- Story Points：5
- Sprint：Sprint 2
- 当前状态：Doing

## 3. 验收标准

### AC1：识别技能 Gap

系统能够根据岗位要求和 US05 技能匹配结果，识别需要补强的技能。

### AC2：识别经历 Gap

系统能够根据岗位工作内容与 US06 经历匹配结果，识别缺少直接项目或实习证据的部分。

### AC3：区分能力不足与证据不足

当个人画像未明确说明某项技能或技术栈时，系统不能直接认定用户完全不会该技能。

### AC4：提供可执行建议

针对主要 Gap，给出具体的学习、练习或项目实践建议，而不仅仅是“提升编程能力”等泛泛描述。

### AC5：设置优先级

补强任务能够标记 P0、P1、P2，并说明优先处理的理由。

### AC6：提供验收标准

主要补强任务能够给出可检查的预期产出或验收条件。

### AC7：区分现有能力与未来计划

系统不能把尚未完成的练习项目写成用户已经完成的项目经历。

### AC8：展示完整结果

页面能够展示技能缺口、经历缺口、补强计划、快速行动、现有优势和风险提示。

### AC9：保留结构化结果

页面可以查看接口返回的完整 JSON，方便后续调试和验收。
