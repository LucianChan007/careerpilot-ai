# Sprint 2 - US05 技能匹配

## 1. User Story

**US05：技能匹配**

作为大学生求职者，我希望系统能够将岗位要求的技能与我的个人技能、项目经历和实习经历进行匹配，并说明匹配依据，从而了解自己与岗位技能要求之间的差距。

## 2. 需求来源

US04 完成后的功能迭代。

US04 已经能够判断岗位的基本硬性条件，但技能维度仍需要进一步分析，因此在 US05 中增加更细粒度的技能匹配能力。

## 3. Sprint 目标

1. 获取岗位明确要求的技能。
2. 获取用户个人画像中的技能、项目和实习经历。
3. 对每项岗位技能进行逐项匹配。
4. 输出技能匹配状态。
5. 展示具体技能证据。
6. 汇总技能缺口。
7. 输出整体技能匹配结论。
8. 处理 C/C++ 等相关技能表达，避免简单字符串匹配产生误判。

## 5. 验收标准

### 技能匹配

对于岗位中的每项 required_skills：

系统返回：

- skill
- status
- evidence
- explanation

其中 status 只能为：

- 满足
- 部分匹配
- 信息不足
- 不匹配

### 技能证据

证据可以来自：

- 用户技能
- 用户项目经历
- 用户实习经历

### 技能缺口

系统能够汇总当前无法满足或信息不足的技能。

### 整体结论

系统能够根据各项技能匹配情况输出整体技能匹配结论。

## 6. 测试案例

### 测试案例 A

岗位：

C++开发实习生

技能：

C/C++、QT

个人画像：

当前用户真实个人画像。

预期：

C/C++ 能够结合用户个人技能、项目或实习经历进行判断。

QT 如果个人画像中没有明确证据，则返回“信息不足”或“不匹配”，不得虚构证据。

### 测试案例 B

岗位包含用户明显没有的技能，例如：

Rust、Go 等。

预期：

系统能够识别技能缺口，并说明个人画像中缺少相关证据。
