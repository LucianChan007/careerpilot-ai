# Sprint 2 - US05 技能匹配

## 1. User Story

**US05：技能匹配**

作为大学生求职者，我希望系统能够将岗位要求的技能与我的个人技能、项目经历和实习经历进行匹配，并说明匹配依据，从而了解自己与岗位技能要求之间的差距。

## 2. 需求来源

US04 完成后的功能迭代。

US04 已经可以判断岗位的基本硬性条件，但对技能维度的分析还不够细，因此在 US05 中进一步分析岗位技能与用户个人技能、项目经历和实习经历之间的关系。

## 3. Sprint 目标

1. 获取岗位明确要求的技能。
2. 获取用户个人画像中的技能、项目经历和实习经历。
3. 对每项岗位技能进行逐项匹配。
4. 输出技能匹配状态。
5. 展示具体技能证据。
6. 汇总技能缺口。
7. 输出整体技能匹配结论。
8. 对 C/C++、Qt 等技能表达进行合理处理，减少简单字符串匹配带来的误判。

## 4. 实现内容

### 后端

- 新增 `backend/app/skill_schema.py`
- 新增 `backend/app/skill_service.py`
- 新增 `POST /api/jd/skills-match`
- 自动读取 `backend/data/profile.json`
- 调用 LLM 分析岗位技能与用户技能、项目、实习经历之间的关系
- 输出技能状态、证据、解释、Gap 和补强建议

### 前端

- 新增 `backend/static/skills.html`
- 展示岗位名称
- 展示整体技能匹配结论
- 展示岗位技能数量
- 展示满足、部分匹配、信息不足、技能缺口数量
- 展示每项技能的匹配状态
- 展示技能证据和解释
- 展示技能缺口
- 展示技能补强建议

### 页面流程

```text
US03：JD 解析
    ↓
US04：硬性条件匹配
    ↓
US05：技能匹配
```

## 7. 自测与迭代

本阶段重点从“是否拥有某项技能”进一步扩展到“岗位技能与个人技能、项目和实习经历之间的证据关联”。

## 8. 后续迭代方向

根据 US05 测试结果，将需要继续优化的技能匹配问题加入后续 Product Backlog。

候选方向：

- 技能同义词与别名归一化
- 更细粒度的技能熟练程度判断
- 项目与岗位技能的直接关联
- 技能 Gap 的针对性补强建议
